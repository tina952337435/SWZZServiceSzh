# 水利片水位预测接口 — 前端对接文档

## 1. 接口信息

**请求方式**：POST
**URL**：`http://{服务地址}:8808/SWZZ_SLP_FORECAST/query`

**入参**：

```json
{
  "ddId": "20260804193401562492",
  "stime": "2026-08-14 14:00:00"
}
```

| 参数 | 说明 |
|------|------|
| `ddId` | 预报方案ID（前端下拉选择） |
| `stime` | 选择的时间 |

## 2. 响应格式

```json
{
  "IsSuccess": true,
  "data": [
    {
      "xh": 1,
      "slpName": "嘉宝北片",
      "area": 698.77,
      "stnmList": "嘉定南门,罗店",
      "yjSw": 3.3,
      "cSw": 2.7,
      "xjjSw": 3.2,
      "bzSw": 3.87,
      "formulaA": 0.9406,
      "formulaB": 46.007,
      "formulaC": -10.631,
      "predictSw": "3.50",
      "actualSw": "2.85",
      "predictDiffBz": "-0.37",
      "predictDiffXjj": "0.30",
      "actualDiffBz": "-1.02",
      "actualDiffXjj": "-0.35"
    }
  ]
}
```

## 3. 字段含义

| 字段 | 含义 | 类型 |
|------|------|------|
| `xh` | 序号 | number |
| `slpName` | 水利片名称 | string |
| `area` | 面积(km²) | number |
| `stnmList` | 站点名称列表 | string |
| `yjSw` | 预降水位（基准值，前端可改） | number |
| `cSw` | 常水位 | number |
| `xjjSw` | 新警戒水位 | number |
| `bzSw` | 保证水位 | number |
| `formulaA/B/C` | 库容公式系数 | number |
| `predictSw` | 模型预测水位 | string |
| `actualSw` | 实测水位 | string |
| `predictDiffBz` | 预测水位−保证水位(米) | string |
| `predictDiffXjj` | 预测水位−新警戒水位(米) | string |
| `actualDiffBz` | 实测水位−保证水位(米) | string |
| `actualDiffXjj` | 实测水位−新警戒水位(米) | string |

## 4. 库容计算公式

```
库容 f(x) = formulaA × x² + formulaB × x + formulaC
```

其中 x 是水位。**任意两个水位的库容差 = f(水位A) − f(水位B)**

## 5. 前端需要计算的 10 个库容差

```
1. 模型选择水位距当前水位库容差   = f(predictSw) − f(actualSw)
2. 模型选择水位距常水位库容差     = f(predictSw) − f(cSw)
3. 模型选择水位距保证水位库容差   = f(predictSw) − f(bzSw)
4. 模型选择水位距新警戒水位库容差 = f(predictSw) − f(xjjSw)
5. 实测水位距常水位库容差         = f(actualSw) − f(cSw)
6. 实测水位距保证水位库容差       = f(actualSw) − f(bzSw)
7. 实测水位距新警戒水位库容差     = f(actualSw) − f(xjjSw)
8. 预降水位距常水位库容差         = f(预降水位) − f(cSw)
9. 预降水位距保证水位库容差       = f(预降水位) − f(bzSw)
10. 预降水位距新警戒水位库容差    = f(预降水位) − f(xjjSw)
```

> 注意：第 8、9、10 项的"预降水位"是前端输入框里的值（用户可动态调整），不是固定的 `yjSw`。`yjSw` 只是初始默认值。

## 6. 前端 JS 完整示例

```javascript
// 请求接口
const res = await fetch('/SWZZ_SLP_FORECAST/query', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ ddId: 'xxx', stime: '2026-08-14 14:00:00' })
});
const { data } = await res.json();

// 库容函数
function capacity(sw, a, b, c) {
  sw = Number(sw);
  return a * sw * sw + b * sw + c;
}

data.forEach(item => {
  const { predictSw, actualSw, cSw, bzSw, xjjSw, formulaA, formulaB, formulaC } = item;

  // 用户输入框改动时，重新计算 8/9/10
  const inputYjSw = 用户输入的预降水位;

  const calc = {
    diff1: capacity(predictSw, formulaA, formulaB, formulaC) - capacity(actualSw, formulaA, formulaB, formulaC),
    diff2: capacity(predictSw, formulaA, formulaB, formulaC) - capacity(cSw, formulaA, formulaB, formulaC),
    diff3: capacity(predictSw, formulaA, formulaB, formulaC) - capacity(bzSw, formulaA, formulaB, formulaC),
    diff4: capacity(predictSw, formulaA, formulaB, formulaC) - capacity(xjjSw, formulaA, formulaB, formulaC),
    diff5: capacity(actualSw, formulaA, formulaB, formulaC) - capacity(cSw, formulaA, formulaB, formulaC),
    diff6: capacity(actualSw, formulaA, formulaB, formulaC) - capacity(bzSw, formulaA, formulaB, formulaC),
    diff7: capacity(actualSw, formulaA, formulaB, formulaC) - capacity(xjjSw, formulaA, formulaB, formulaC),
    diff8: capacity(inputYjSw, formulaA, formulaB, formulaC) - capacity(cSw, formulaA, formulaB, formulaC),
    diff9: capacity(inputYjSw, formulaA, formulaB, formulaC) - capacity(bzSw, formulaA, formulaB, formulaC),
    diff10: capacity(inputYjSw, formulaA, formulaB, formulaC) - capacity(xjjSw, formulaA, formulaB, formulaC)
  };
});
```
